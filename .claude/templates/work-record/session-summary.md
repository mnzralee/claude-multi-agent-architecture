# Session Summary Template

Use this template to conclude each session.

---

```markdown
### Session Summary

**Objective:** [What we set out to do]
**Outcome:** [What we achieved]
**Key Insight:** [Most important thing learned]
**Status:** COMPLETE / IN PROGRESS / BLOCKED

**Metrics:**
- Files changed: [N]
- Tests added/modified: [N]
- Time estimate: [if tracked]

**Commits:**
- `abc123` - [commit message]
- `def456` - [commit message]

---

### Challenges Encountered

**Challenge 1: [Title]**
- **Problem:** [What went wrong]
- **Resolution:** [How we fixed it]
- **Learning:** [What we learned from it]

---

### What's Next

1. [Next task or follow-up item]
2. [Additional item]
3. [Additional item]
```

---

## Guidelines

### Status Values
- **COMPLETE**: All objectives achieved, verified, committed
- **IN PROGRESS**: Work started but not finished
- **BLOCKED**: Cannot proceed due to external dependency

### Metrics
- Keep simple and relevant
- Don't obsess over exact counts
- Focus on magnitude (small/medium/large change)

### Commits
- List all commits made during session
- Include commit hashes and messages
- Helps trace changes later

### Challenges Encountered
- Document problems faced during implementation
- Include how they were resolved
- Capture learnings for future reference

### What's Next
- Clear action items for follow-up
- Helps next session start productively
- Prioritize items if multiple
