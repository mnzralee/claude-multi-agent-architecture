# Daily Summary Template

Use this template at the end of each day to compile session summaries.

---

```markdown
---

## Daily Summary: [YYYY-MM-DD]

### The Day in Brief

[1-2 paragraph narrative summarizing what was accomplished today.
Write as if explaining to a colleague what you did.]

---

### Sessions Completed

| Session | Focus | Outcome |
|---------|-------|---------|
| Session 1: [Title] | [Focus area] | COMPLETE/IN PROGRESS |
| Session 2: [Title] | [Focus area] | COMPLETE/IN PROGRESS |

---

### Key Achievements

**[Category 1]:**
- [Achievement with brief context]
- [Achievement with brief context]

**[Category 2]:**
- [Achievement with brief context]

---

### Challenges Overcome

| Challenge | Solution | Learning |
|-----------|----------|----------|
| [Challenge] | [How resolved] | [Key insight] |

---

### Statistics

- Sessions: [N]
- Files changed: [~N]
- Tests added: [N]
- Commits: [N]

---

### Tomorrow's Focus

1. [Priority 1 - most important]
2. [Priority 2]
3. [Priority 3]

---

### Day's Key Insight

[The one thing worth remembering from today's work.
Make it actionable and memorable.]

---
```

---

## Guidelines

### The Day in Brief
- Write in first person plural ("We accomplished...")
- Keep it high-level but meaningful
- Should be understandable without reading session details

### Sessions Table
- Quick reference to all sessions
- Link to detailed session records if possible
- Use consistent status terminology

### Key Achievements
- Group by category (Feature, Bug Fix, Infrastructure, etc.)
- Focus on outcomes, not activities
- Include enough context to be meaningful

### Challenges Overcome
- Capture significant hurdles
- Document solutions and learnings
- Helps build organizational knowledge

### Statistics
- Keep approximate if exact counts are tedious
- Focus on order of magnitude
- Useful for understanding session scale

### Tomorrow's Focus
- Prioritized list of next steps
- Helps start next day productively
- Keep to 3-5 items max

### Day's Key Insight
- Single most valuable learning
- Should be actionable
- Something future readers can apply
