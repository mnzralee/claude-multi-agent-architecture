# Problem Statement Template

Use this template to document the problem or challenge being addressed.

---

```markdown
### The Challenge: [Problem Title]

**What We Faced:**
[Detailed description of the problem, bug, or feature requirement. Include:
- What was happening (symptoms)
- What was expected instead
- Who/what was affected
- When it was discovered or requested]

**User/Business Impact:**
[Why this matters - how it affects users or the business]

**Technical Complexity:**
[What makes this technically interesting or challenging]
```

---

## Guidelines

### For Bug Reports
- Include exact error messages
- Describe reproduction steps
- Note environment details
- Mention when it started happening

### For Feature Requests
- Include the user story if available
- Describe the expected behavior
- Note any constraints or requirements
- Mention related existing functionality

### For Refactoring
- Explain what prompted the refactoring
- Describe current state problems
- Define target state
- Note any risks
